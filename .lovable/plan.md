# تطبيق أندرويد عبر PWABuilder

## الفكرة
بدل الغلاف الحالي، نجعل الموقع المنشور «تطبيق ويب قابلًا للتثبيت» ثم نولّد منه حزمة أندرويد عبر pwabuilder.com. التطبيق يعمل بمحرك Chrome الحديث في الهاتف، فتنتهي مشكلة الشاشة البيضاء على الهواتف القديمة.

## ملاحظات مهمة قبل البدء
- يحتاج الهاتف إلى Chrome (موجود في أغلب الهواتف).
- أول فتح يحتاج إنترنت؛ بعده تعمل الشاشات والصور والصوتيات بدون نت. الإرسال والطلبات تحتاج إنترنت كالعادة.
- التحديثات تصل تلقائيًا عند النشر، بدون تحميل حزمة جديدة.
- الحزمة الجديدة باسم مختلف عن القديمة، فتُثبت بجانبها (يمكن حذف القديمة).

## الخطوات
1. تجهيز بيانات التطبيق: الاسم «تمكين»، الأيقونات بكل المقاسات، الألوان الكحلية، ملء الشاشة.
2. تفعيل العمل بدون إنترنت في الموقع المنشور فقط (لا يؤثر على المعاينة).
3. النشر، ثم فحص الموقع بأداة PWABuilder للتأكد أنه مقبول.
4. توليد حزمة أندرويد من PWABuilder وتوقيعها بمفتاح دائم محفوظ في الملفات الخاصة.
5. ربط الحزمة بالموقع حتى يفتح بدون شريط عنوان المتصفح.
6. تجربتها على الهاتف الوهمي (الفتح، ثم قطع النت وإعادة الفتح) وإرسال لقطات.
7. عند النجاح فقط: رفعها في صفحة التنزيلات بدل v4.

## تفاصيل تقنية
- vite-plugin-pwa بـ generateSW، `injectRegister: null`، `devOptions.enabled=false`، تسجيل من وحدة واحدة محمية (لا تسجيل في المعاينة/iframe، و`?sw=off`)، NetworkFirst للصفحات، CacheFirst للملفات المجزّأة، precache للصوتيات وصفحات الكتالوج والخطوط.
- تحديث `public/manifest.webmanifest` (id، start_url، display: fullscreen، icons 192/512/maskable).
- توليد APK عبر API PWABuilder (CloudAPK) بحزمة `tech.tamkeen.app` وتحديث `public/.well-known/assetlinks.json` ببصمة المفتاح.
- تحديث قاعدة AGENTS.md الخاصة بغلاف أندرويد لتصبح TWA عبر PWABuilder، و`src/routes/downloads.tsx`.
